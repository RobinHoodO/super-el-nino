# Super El Nino plugin package

This folder packages the existing Super El Nino remote MCP service for the OpenAI Plugins directory.

The package deliberately does not contain credentials, reviewer accounts, or the hosted application source. The current endpoint is configured in `mcp.json`.

Before public submission, add verified HTTPS support, privacy-policy, and terms-of-service URLs to `plugin.json`; complete the MCP domain challenge in OpenAI Platform; and provide the required reviewer materials.
